---
name: review
description: 直近の変更を code-reviewer サブエージェントでレビューし、重大／要修正を直す。段階の終わりや commit 前に使う。
---
次の手順で進めてください。

1. `git diff` と `git status` で直近の変更範囲を把握する
2. code-reviewer サブエージェントに、変更ファイル一覧とプロジェクトの仕様書（docs/ 配下や CLAUDE.md）の場所を渡してレビューさせる
3. 返ってきた指摘のうち「重大」「要修正」をすべて直す。「提案」は採否を1行ずつ書く
4. テストを実行して結果を報告する
5. 直した内容を3行以内でまとめる
